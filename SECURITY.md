# Politique de sécurité

Ne signalez pas publiquement une vulnérabilité. Pour le moment, contactez les mainteneurs via un canal privé défini par l'organisation GitHub.

Ne soumettez jamais de données personnelles, pièces d'identité, secrets ou informations de paiement dans les issues.

Cette version est un socle de développement et ne doit pas traiter de données sensibles réelles.
